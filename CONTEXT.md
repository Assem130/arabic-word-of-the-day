# Kalimat

Kalimat is a local-first Arabic learning experience built around a daily word and a learner's retained progress.

## Language

**Daily assignment**:
The word selected for a learner on one local calendar date.
_Avoid_: daily card, daily item

**Daily review**:
A learner's recall rating for a previously encountered word, used to schedule its next appearance.
_Avoid_: practice, quiz

**Learner profile**:
The local record of assignments, word state, preferences, and review history for the extension.
_Avoid_: account, user record
